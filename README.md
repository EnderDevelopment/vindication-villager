# Vindication Villager Minecraft Plugin

Vindication Villager is a Minecraft plugin that adds a special vindicator mob that trades like a villager but accepts dirt as currency. This Minecraft plugin transforms a standard vindicator into a unique trading NPC that offers powerful and overpowered items in exchange for dirt. With Vindication Villager, players can summon this custom mob, interact with it to open a trading interface, and purchase valuable resources like diamonds, netherite ingots, enchanted gear, and rare items using only dirt as payment. The plugin is designed for Paper servers running Minecraft 1.21, providing a fun and balanced gameplay addition that rewards resource gathering and exploration.

## Install

1. Download the Vindication Villager plugin JAR file.
2. Place the JAR file into your server's `plugins` folder.
3. Restart your server or use a plugin manager to load the plugin.

## Use

1. Once the plugin is loaded, any player can spawn a Vindication Villager by running the command `/vindivillager` (or the alias `/vvillager`).
2. Right-click on the spawned Vindication Villager to open the trading interface.
3. The trading GUI will show nine available items for trade.
4. Select an item from the GUI to purchase it. Each item has a dirt cost displayed in the trade.
5. Make sure you have enough dirt in your inventory to complete the trade.
6. The purchased item will be added to your inventory, and the dirt will be removed.

### Trades Available

- **Diamond** - 1 dirt
- **Netherite Ingot** - 8 dirt
- **Emerald (x16)** - 2 dirt
- **Blade of the Vindicator** (Diamond Sword, Sharpness V) - 16 dirt
- **Dirt Digger's Pick** (Netherite Pickaxe, Efficiency V) - 24 dirt
- **Crossbone Bow** (Bow, Power V) - 20 dirt
- **Sky Wings** (Elytra, Unbreaking III) - 64 dirt
- **Bastion Shield** (Shield, Unbreaking III) - 12 dirt
- **Beacon** - 32 dirt

The Vindication Villager will make a vindicator sound when interacted with and will make villager sounds during successful or failed trades. This plugin adds a unique gameplay element that rewards players who collect dirt while exploring and mining.
